## Ограничения

Это синтетическая однопоточная задача в памяти. Измерение включает Python, но не SQL, сеть и дисковый ввод-вывод. Нагрузки с одним запросом или маленьким объемом данных могут дать другую картину. Пик tracemalloc не равен RSS процесса. cProfile добавляет накладные расходы и используется для поиска горячих функций, а не для расчета приведенного ускорения.

Сырые замеры: timings.csv. Контекст запуска: environment.json. Профили: profile_scan.txt и profile_indexed.txt.
